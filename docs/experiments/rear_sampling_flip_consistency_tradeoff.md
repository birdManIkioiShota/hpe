# 後方サンプリング率と左右反転整合性重みの交互作用評価

## 概要

SixDRepNet360-ResNet50のモデル構造を固定し、後方姿勢の推定精度を改善しながら、AGORA-HPEの正面・側面姿勢と、AFLW2000および300W-LPの評価性能を維持できる学習条件を調査しました。

学習時の後方姿勢サンプリング率を、学習データに含まれる自然比率1.743%、5%、25%の3段階とし、後方画像に適用する左右反転整合性損失の重みを0、0.2、1.0の3段階とした、合計9条件を比較しています。各条件は、300W-LPとPanopticで学習された同一の配布checkpointから独立に開始し、同一の学習設定で10 epoch学習しました。

外部評価では、AGORA-HPE、AFLW2000、300W-LP、DAD-3DHeads validationを使用しました。固定epoch 10で比較した結果、左右反転整合性重み0.2には後方サンプリング率とは独立した改善効果がありました。ただし、その追加効果は後方サンプリング率が高くなるほど小さくなりました。重み1.0では大誤差率が低下する条件がある一方、AGORA-HPEと300W-LPの側面姿勢に明確な退行が発生しました。

結果は単一の総合点に集約せず、後方精度と非後方性能のPareto関係として整理します。自然比率・重み0は確認した主要グループに平均誤差の退行がなく、自然比率・重み0.2は300W-LP側面の0.126°退行と引き換えにAGORA-HPE後方を3.081°改善しました。25%・重み0.2はAGORA-HPE後方を5.583°改善しましたが、複数の正面・側面グループで退行しています。

## 目的

本実験の目的は、次の3点を分離して測定することです。

1. 後方姿勢の学習頻度を増やしたときの改善量と、正面・側面姿勢に対する退行量を測定する。
2. 左右反転整合性損失の効果を、後方姿勢のサンプリング増加による効果から分離する。
3. 後方精度と、AGORA-HPEの正面・側面、AFLW2000、300W-LP、DAD-3DHeads validationに対する性能保持のPareto関係を明らかにする。

対象モデルは、すべての条件でSixDRepNet360-ResNet50に固定しました。蒸留用teacherには、学習開始時と同じベースモデルを使用しました。

## 用語と指標

### 学習時の姿勢区分

学習用manifestの回転行列からhead-localの`+Z`軸をhead-forward方向として取り出し、XZ平面へ射影した方位角`azimuth`を使用します。

| 姿勢区分 | 定義 |
|---|---|
| 正面 | `|azimuth| < 60°` |
| 側面 | `60° <= |azimuth| < 120°` |
| 後方近傍 | `120° <= |azimuth| < 150°` |
| 深い後方 | `150° <= |azimuth| <= 180°` |

後方姿勢は方位角の正負と角度帯を組み合わせ、`negative 120–150°`、`negative 150–180°`、`positive 120–150°`、`positive 150–180°`の4区分として扱います。

### 外部評価時の姿勢区分

外部評価では、評価manifestに保存されたsource yawを使用します。

| 姿勢区分 | 定義 |
|---|---|
| 正面 | `|yaw| < 60°` |
| 側面 | `60° <= |yaw| < 120°` |
| 後方 | `|yaw| >= 120°` |

学習時のhead-forward azimuthと外部評価のsource yawは、同じ数値規約であるとは限りません。このため、内部development splitと外部データセットの姿勢帯は、同じ意味のカテゴリとして比較しますが、サンプル単位で同一の角度とみなしません。

### 評価指標

主指標は、予測回転と正解回転のSO(3) geodesic errorです。単位は度で、小さいほど良い値です。

| 指標 | 意味 |
|---|---|
| mean | 対象サンプルの平均SO(3)誤差 |
| median | SO(3)誤差の中央値 |
| P90 | SO(3)誤差の90パーセンタイル |
| `>90° rate` | SO(3)誤差が90°を超えたサンプルの割合 |

外部評価の差は`candidate - base`で表します。負の値が改善、正の値が退行です。信頼区間には、同一サンプルの誤差差を使用したpaired bootstrapの95%区間を使用します。

### 左右反転整合性損失

左右反転整合性損失は、元画像の予測と、左右反転画像の予測を元の座標系へ戻した回転とのSO(3)距離です。比較する重み0、0.2、1.0は、この損失項を学習損失へ加える際の係数です。

水平反転行列を`M = diag(-1, 1, 1)`、左右反転画像に対する予測回転を`R_flip`とすると、元の座標系に戻した回転は`M R_flip M`です。左右反転整合性損失は、元画像の予測`R`と`M R_flip M`のgeodesic distanceとして計算します。

## 実験設計

### 比較条件

後方サンプリング率と左右反転整合性重みの3×3条件を比較しました。

| 条件ID | 後方サンプリング率 | 左右反転整合性重み |
|---|---:|---:|
| `rear_natural_flip_000` | 自然比率1.743% | 0 |
| `rear_natural_flip_020` | 自然比率1.743% | 0.2 |
| `rear_natural_flip_100` | 自然比率1.743% | 1.0 |
| `rear_005_flip_000` | 5% | 0 |
| `rear_005_flip_020` | 5% | 0.2 |
| `rear_005_flip_100` | 5% | 1.0 |
| `rear_025_flip_000` | 25% | 0 |
| `rear_025_flip_020` | 25% | 0.2 |
| `rear_025_flip_100` | 25% | 1.0 |

すべての条件は同一のベースcheckpointから独立に開始しました。同じ後方サンプリング率の3条件では、epochごとのサンプル順序と画像augmentationが一致するようにseedを固定しています。これにより、同じ後方比率内では左右反転整合性重みだけが異なる比較になります。

### 後方サンプリング

1 epochは451,072サンプルです。実データ451,090件からeffective batch sizeの倍数へ切り下げています。

後方4区分の構成比は、元のtrainデータに含まれる区分比率を維持しました。後方4区分を均等化していません。各epochの計画値は次のとおりです。

| 後方比率 | 後方draw数 | unique samples | repeated draws |
|---|---:|---:|---:|
| 自然比率 | 7,861 | 451,072 | 0 |
| 5% | 22,554 | 436,379 | 14,693 |
| 25% | 112,768 | 346,165 | 104,907 |

25%条件では、後方サンプルの反復が多くなります。この反復量は、後方比率を高くした条件の過学習リスクを解釈する際の重要な要素です。

### 学習損失

学習損失は次の3項から構成します。

```text
L = L_supervised + L_distillation + lambda_flip * L_flip_consistency
```

- `L_supervised`は、全サンプルの正解回転行列に対するSO(3) geodesic lossです。
- `L_distillation`は、後方以外のサンプルについて、ベースモデルの予測へ近づけるSO(3) geodesic lossです。重みは1.0です。
- `L_flip_consistency`は、後方サンプルだけに適用する左右反転整合性損失です。`lambda_flip`を0、0.2、1.0で比較しました。

### 内部checkpoint選択と主比較

各epoch後に、VGGHeadsとDAD-3DHeads train由来のdevelopment splitを評価しました。

内部best checkpointの選択では、正面・側面のmeanとP90がそれぞれ学習前より悪化しないことを要求しました。条件を満たすcheckpointについて、後方4区分の最大P90、後方全体P90、後方4区分の最大90°超過率、後方全体meanの順に比較しています。

一方、9条件の主比較と外部評価には、すべて固定epoch 10のcheckpointを使用しました。条件によって異なるepochを選ぶ影響を排除し、後方比率と左右反転整合性重みの比較を揃えるためです。保存されている`best.pth`は主比較には使用していません。

### 結果の整理基準

外部評価結果には、後方性能と非後方性能を一つの数値へ合成する総合scoreを設定していません。次の軸を個別に示し、一方を改善するために他方がどの程度変化したかを比較します。

- 後方性能は、主にAGORA-HPE後方のmean、P90、90°超過率で評価します。
- 非後方性能は、AGORA-HPE正面・側面、AFLW2000全体、300W-LP全体・側面、DAD-3DHeads validation全体・側面で評価します。
- DAD-3DHeads validation後方は47件のため、補助的な結果として扱います。
- paired bootstrapの95% CIが0を跨がない差を、統計的に方向が明確な変化として記述します。

この整理は外部評価結果の報告に使用するものであり、学習中のcheckpoint選択には使用していません。

本報告でいうPareto候補は、ある評価軸をさらに改善しようとすると、少なくとも一つの別の評価軸が悪化する条件を指します。用途ごとの許容退行量を定めていないため、Pareto候補の中から単一の最良条件は指定しません。

## 効果の分離

### 左右反転整合性重み0から0.2への変化

同じ後方サンプリング率で、重みだけを0から0.2へ変更したときの追加改善量は次のとおりです。

| 後方比率 | 内部dev後方mean | AGORA後方mean | DAD全体mean |
|---|---:|---:|---:|
| 自然比率 | -5.900° | -2.535° | -1.337° |
| 5% | -5.524° | -2.424° | -1.863° |
| 25% | -2.193° | -0.864° | -0.485° |

重み0.2には、すべての後方比率で後方改善への寄与があります。ただし、25%条件では追加効果が小さくなっています。後方教師サンプルを大量に反復する条件では、左右反転整合性が提供する追加情報の限界効用が低下したと解釈できます。

### 後方サンプリング率の変化

左右反転整合性重み0.2に固定したときの結果は次のとおりです。

| 後方比率 | AGORA後方mean | AGORA正面のベース差 | DAD全体mean | 300W側面のベース差 |
|---|---:|---:|---:|---:|
| 自然比率 | 34.819° | +0.067° | 29.385° | +0.126° |
| 5% | 33.811° | +1.075° | **28.744°** | +0.194° |
| 25% | **32.317°** | +3.060° | 30.081° | +0.326° |

後方サンプリング率を上げるほどAGORA-HPE後方は改善しました。一方、AGORA-HPE正面と300W-LP側面の退行が単調に増えています。DAD全体は5%で最小となり、25%では悪化しました。25%への増加は、後方性能を優先した分布シフトとして現れています。

### 左右反転整合性重み1.0

重み1.0は、DAD-3DHeads validation全体とAGORA-HPE後方の90°超過率を大きく改善しました。しかし、AGORA-HPE側面と300W-LP側面に一貫した退行が発生しました。

5%・重み1.0では、DAD全体が5.874°改善する一方、DAD側面は2.995°、AGORA-HPE側面は8.214°悪化しています。DAD全体は正面サンプルが89.1%を占めるため、全体平均だけでは側面退行を検出できません。

重み1.0は、後方の極端な失敗を抑える効果と、非後方グループの誤差を増加させる効果を同時に示しました。AGORA-HPEおよび300W-LPの側面性能を保持する制約を課す場合、比較した重み1.0の条件はその制約を満たしません。

## 目的別のPareto候補

### 観測した非後方グループで退行がない条件

自然比率・重み0は、確認した主要外部グループすべてで平均誤差がベースモデル以下でした。AGORA-HPE後方の改善は0.546°で、比較した9条件の中では最小です。

### 小さな局所退行で後方改善を拡大する条件

自然比率・重み0.2は、AGORA-HPE後方を3.081°、DAD全体を2.097°改善し、AGORA-HPE正面・側面では統計的に方向が明確な退行を生じさせませんでした。一方、300W-LP側面には0.126°の退行があります。自然比率・重み0より後方改善を拡大し、5%・0.2および25%・0.2より非後方グループの退行を小さくした中間的な条件です。

この条件は後方サンプルを自然比率のまま使用するため、5%・25%条件で発生する後方サンプルの反復もありません。高い後方サンプリング率に依存せず、左右反転整合性から改善を得られることを示しています。

### AGORA-HPE後方の誤差を最小化する条件

25%・重み0.2は、AGORA-HPE後方mean、P90ともに最小です。一方、AGORA-HPE正面・側面、AFLW2000全体、300W-LP全体および側面で退行しています。この条件の採用には、これらの退行を許容できる用途上の根拠が必要です。

## 制約

- 各条件はseed 42の1回だけ実行しています。条件間の小さな差について、seedを変えた再現性は確認していません。
- 比較した後方比率は自然比率、5%、25%の3点、左右反転整合性重みは0、0.2、1.0の3点です。連続的な応答曲線は測定していません。
- 主比較は固定epoch 10です。内部development splitで選択したbest checkpointの外部評価は含まれていません。
- DAD-3DHeads validationの後方サンプルは47件です。DAD全体の改善は主に正面サンプルの結果を反映します。
- AFLW2000と300W-LPには評価manifest上の後方サンプルがなく、後方性能を直接評価できません。
- 学習時のhead-forward azimuthと外部評価のsource yawは異なる角度規約を含みます。
- VGGHeadsの姿勢annotationは生成された推定値であり、motion-captureによるground truthではありません。
- 25%条件では1 epochあたり104,907回の重複drawがあり、後方サンプルに対する反復学習が多くなっています。
- 9条件の外部benchmark結果を観測済みです。この結果を使用して同じbenchmark上で追加の細かなハイパーパラメータ探索を行うと、benchmarkへの適合が進みます。追加実験では条件と判断基準を事前に固定し、独立評価を確保する必要があります。

## 結論

左右反転整合性重み0.2は、後方サンプリング率とは独立して後方姿勢の推定精度を改善しました。自然後方比率でも、AGORA-HPE後方meanを37.900°から34.819°へ、P90を71.800°から61.244°へ低下させています。

後方サンプリング率を5%、25%へ上げるとAGORA-HPE後方はさらに改善しましたが、AGORA-HPE正面と300W-LP側面の退行が増えました。25%・重み0.2はAGORA-HPE後方meanを32.317°まで低下させる一方、AGORA-HPE正面を3.060°、300W-LP側面を0.326°悪化させています。

左右反転整合性重み1.0は、DAD-3DHeads validation全体と後方の大誤差率を改善しますが、複数の外部データセットで側面姿勢を悪化させました。内部development splitでも、5%・1.0と25%・1.0は正面・側面のmean/P90保持条件を満たす学習後checkpointを生成できませんでした。

9条件の中に、後方精度とすべての非後方グループを同時に最良化する単一条件はありません。自然比率・重み0は観測した主要グループの平均誤差を維持する端点、自然比率・重み0.2は300W-LP側面の0.126°退行と引き換えに後方改善を拡大する中間点、25%・重み0.2は複数の非後方退行と引き換えにAGORA-HPE後方誤差を最小化する端点です。採用条件は、対象用途が許容できる非後方退行の上限に基づいて、このPareto候補から決定する必要があります。

```bash
uv run python -m experiments.scripts.run_rear_flip_search \
```

```bash
uv run python -m experiments.scripts.evaluate_rear_flip_search \
  --run-id rear_flip_search \
```

```bash
  --name-suffix _dad
```
